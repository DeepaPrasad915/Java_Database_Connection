# Java_Database_Connection
Create Java Database Connectivity
In this project include all Database connection with mysql and procedural Langauage with Downloading all jar libraries.
Using the Statement, PreparedStatement and callable Statement with Insert, Updating, and Deleting the data or query in Table.
Using executeUpdate to firing the Query and executeQuery for selecting and executing Query.
Steps for JDBC:
1: import the packages
2: Load the Driver
3: Create the Connections
4: Create the references of statements
5: Execute the Query
6: Close the statement and Connections
Performing the MYSQl queries merging with Java programming language.
